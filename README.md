# Nicko's Adventure Academy

Build a mobile-first educational game called 'Nicko's Adventures'. Nicko is a lovable gray tabby cat. Target ages 4-8. Every level teaches one life lesson (calling 911, kindness, stranger safety, emotions, fire safety, crossing streets, honesty, teamwork). Gameplay mixes simple platforming with kid-friendly puzzles, matching, sequencing, memory games, and problem-solving. Reward stars, badges, stickers, and unlockable outfits. Narration is encouraging. Bright cinematic visuals, large buttons, accessibility features, save progress, parent dashboard, no ads. Create MVP with title screen, world map, first lesson 'When to Call 911', obstacle course, mini-games, reward screen, and architecture allowing more lessons later.
